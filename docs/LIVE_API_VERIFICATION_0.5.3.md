## 验收原则

- 全部调用均为只读查询，不发起消费请求、不修改上游账户或 Key。
- 本文只记录核对所需的脱敏数值、单位和协议结论，不记录账号名、账号 ID、组织 ID、PAT、API Key、代理 URL 或完整生产响应。
- 接口没有返回的窗口或金额保持缺失，不根据套餐名称、历史值或硬编码规则补齐。
- 金额和单位以查询时的上游返回为准；动态余额会随账户使用发生变化。

## 协议细节

### NewAPI

脱敏只读核对确认账号 quota 和已用值按实例显示设置换算。该实例的 CNY 结果与 quota 数值按约定基数换算一致，不再沿用 USD 默认值。未记录实例地址、账号标识或管理 PAT。

### Command Code

脱敏响应只提供 five-hour 和 weekly 窗口。插件按原始字段映射为“5 小时”和“一周”；month 缺失时不生成虚拟金额，credits 池仍作为独立套餐额度处理。

### Sub2API

核对覆盖官方当前 `/v1/usage` 语义：`quota_limited` 顶层 `remaining` 表示 Key 剩余额度；不限额订阅模式表示订阅剩余额度；钱包模式的顶层 `remaining` 和 `balance` 都表示钱包余额。当前直连场景会收到 Cloudflare `403`，因此部署时必须保留宿主或供应商代理继承，不能静默改为直连。

### 智谱 / Z.ai

套餐接口本身可访问，但本次业务响应为 `success=false`、`code=500`，且当前没有经过验证、可供插件调用的公开现金余额接口。管理页面和 README 记录该限制并提供控制台入口；只有后续取得可验证的官方接口和脱敏响应后，才可把现金余额标记为已支持。

## 剩余风险

- 真实接口字段和错误码可能随供应商升级变化，发布前应重新执行只读核对。
- 上游余额为动态值，本记录用于验证解析语义，不作为长期财务口径。
- 任何后续诊断不得保存或输出真实凭证、完整响应或可识别账户的数据。
