# 上游账户监控 0.5.0 发布说明

发布日期：2026-09-19
上一版本：0.4.1
技术 ID：`upstream-monitor`
动态库名：`upstream-monitor.so`

## 版本目标

0.5.0 处理完整审查中的 36 组问题，重点修复账户身份串用、配置半保存、缓存重启恢复、网络超时与取消、协议单位 / 窗口语义、部分失败、刷新导航和移动端配置。第 09 项智谱 / Z.ai 现金余额经接口核实后记录为外部限制，不声明为已补齐。

## 用户可见变化

- 打开页面立即显示缓存，不等待网络；过期、首次失败和部分失败均有明确时间和原因。
- 后台按 TTL 自动采集宿主凭证和静态 Provider；关闭浏览器后仍按调度运行，插件退出时取消在途任务。
- 重新加载只读取状态；刷新当前只刷新一个账户；刷新全部显式执行全部。任务进度和部分失败可见。
- 供应商备注、协议、PAT、监控开关和阈值草稿不会因切页、轮询或保存失败丢失；并发编辑使用修订冲突保护。
- 取消监控立即移出当前报告但保留历史；重新监控会恢复账户并排队查询；只有清除记录会删除历史。
- 详情只显示当前分组，但计费、倍率、速率限制、Token、费用、每日用量、模型、历史和诊断均可一次切换到达。
- 390、768、1440 宽度以及 CPAMP iframe 亮 / 暗主题下有完整布局和操作回归。

## 数据正确性

- NewAPI 根据实例显示配置处理 USD、CNY、TOKENS、CUSTOM；1000000 / 500000 在 USD 显示 2，在 CNY 且汇率 6.73 时显示 13.46。
- 智谱已用 0.5% 映射为剩余 99.5%，已用 1% 映射为剩余 99%；响应顺序不改变窗口名称。
- Sub2API 日窗口 12/10、周窗口 12/100 时仍显示日窗口超额 2，并至少产生严重告警。
- 套餐到期和窗口重置分开；无明确重置时间时显示未提供。
- 过期或禁用 Key 即使返回 `isValid=true` 也按上游不可用事实处理，参考余额保留但不报告健康。
- Command Code 使用服务端 grant：grant 35、remaining 30 显示 30/35；只返回两个窗口时不伪造第三个。
- 现金阈值支持币种默认和账户覆盖；0.01 CNY 在 critical=1、warning=10 时触发严重告警。

## 存储与兼容

- 偏好格式：`format_version=2`。
- 快照缓存格式：`format_version=2`。
- 两种格式均支持旧格式读取；未来版本、截断 JSON 或身份不一致会保留原文件并报告恢复失败。
- 旧位置型账户只有在匹配唯一且可验证时自动迁移；否则标记 `relink_required`，不会按当前位置继承 PAT。
- PAT 密文从旧账户 ID AAD 迁移到新稳定 ID AAD，原加密密钥保持不变。
- 偏好文件、密钥、缓存和历史是成套数据。回滚到 0.4.1 时必须恢复旧二进制和旧数据，不能只替换 `.so`。

## 安全

- PAT 只返回 `missing`、`ready`、`decrypt_error` 等状态，不回显明文。
- 密钥丢失或错误时保留旧密文，非 PAT 状态和其他账户继续工作。
- 内部 HTTP 默认拒绝，必须按账户显式开启；跨源重定向不携带认证信息继续请求。
- 支持 `inherit`、`direct`、`url` 三态代理及 HTTP、HTTPS、SOCKS5；代理凭据不进入日志。
- Hermes 只读接口继续只接受独立 Bearer Token，不接受 URL 查询参数。

## 外部限制

智谱 / Z.ai 当前没有经过验证、可供插件调用的公开现金余额接口。页面显示“暂不支持自动查询现金余额”，给出控制台入口，并保留套餐周期额度查询；不会把套餐额度当成现金或生成虚假金额。

每个压缩包只包含对应架构的 `upstream-monitor.so`、中文 README 和 LICENSE。生成的头文件、缓存、截图、密钥、PAT、真实账户响应和本地构建目录不得发布。

## 升级步骤

1. 停止 CPA，备份旧插件、偏好文件、偏好密钥、快照缓存和旧二进制。
2. 记录备份文件权限和 SHA-256，保持密钥文件原权限。
3. 替换对应架构的 `upstream-monitor.so`，保留相同文件名。
4. 启动 CPA，确认偏好格式迁移、缓存恢复和目录同步状态。
5. 检查每个账户的 PAT 状态；`relink_required` 或 `decrypt_error` 需按提示重新关联或恢复正确密钥。
6. 分别在桌面、平板、手机和 CPAMP iframe 中执行一次重新加载、刷新当前和刷新全部。

详细回滚流程见 `docs/MIGRATION_AND_ROLLBACK.md`。
